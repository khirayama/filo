# filo Screens

## 画面

- サインアップ・サインイン
- 購読一覧／購読管理
- フィード追加
- タグ管理
- 購読記事一覧
- 処理ステータス
- 設定
- アカウント削除

## 記事一覧

- `/articles` を起動後の主要画面とする。
- 全購読、購読単体、タグ、リーディングリスト、ブックマークの一覧を表示する。
- 記事には feed 名、タイトル、RSS プレビュー、時刻、既読状態、リーディングリスト状態、ブックマーク状態を表示する。
- 記事一覧は既読／未読で絞り込みでき、各記事を明示的に既読／未読へ変更できる。
- 記事タップでは元記事 URL を開く。
- リーディングリストには「閲覧開始」と「読み上げ開始」を置き、追加順で固定したセッションの最初の未読記事を開く。
- リーディングリストには、確認後に既読記事をまとめて削除するボタンを置く。
- iOS / Android はアプリ内ブラウザ、Web は Browser Extension と専用の新規タブを使い、前へ・再生／一時停止・次へ・音声・言語・速度を下部に表示する。Web の前後移動では専用タブを再利用し、iOS / Android はアプリ内ブラウザ内でカルーセル相当の遷移を行う。
- Browser Extension のポップアップにもログイン状態、リーディングリスト、同等の再生・音声・言語・速度操作を表示する。
- Web 本体の Browser Extension が未インストールまたは未検出の場合、リーディングリストの閲覧開始・読み上げ開始ボタンは無効にする。
- 記事一覧の更新は feed fetch を enqueue し、status API の完了後に一覧を再読込する。
- 翻訳トグルを 1 つ持ち、表示中の記事タイトルを端末内翻訳する。
- 翻訳済みタイトルは行ごとに原文へ戻せる。
- スクロールで追加された記事も、翻訳トグルが有効なら翻訳対象にする。
- 購読がない場合はフィード追加導線を表示し、取得中は取得状態を表示する。
- ブラウザ拡張のポップアップと iOS / Android の共有シートから任意 URL をリーディングリストへ追加できる。

## リーディング状態

- 記事を開くだけ、一時停止しただけでは既読にしない。
- 前後移動時は移動元、読み上げ完了時は完了記事を既読にする。
- 読み上げ完了後は次の記事へ進み、最後の記事で停止する。
- フィード由来の記事と、ブラウザ／共有から保存した任意 URL を対象にする。
- Readability の本文抽出は短い結果を除外する保守的な設定で行い、抽出漏れよりも本文ノイズを許容する。抽出に失敗した場合はサーバーの保存済み本文抽出へフォールバックする。
