# Keyboard shortcuts

Web、Browser Extension、iOS、Androidで、物理キーボードが利用できる場合の共通ショートカット。
入力欄・セレクトボックス・編集可能な要素にフォーカスがある場合は、ショートカットを発動しない。

## Article list

| Key | Action |
| --- | --- |
| `J` / `↓` | 次の記事を選択 |
| `K` / `↑` | 前の記事を選択 |
| `Enter` / `O` | 選択中の記事を開く |
| `V` | 選択中の記事を元記事として開く |
| `M` | 選択中の記事を既読／未読にする |
| `S` | 選択中の記事をリーディングリストに追加／削除 |
| `B` | 選択中の記事をブックマーク／解除 |
| `R` | フィードを更新 |
| `Shift+A` | 現在のスコープをすべて既読にする |
| `?` | ショートカット一覧を表示 |

`Shift+A`、`J`、`K`、`R`、`M`、`O`、`V` はFeedlyのショートカットと同じ意味に寄せる。
FiloではFeedlyの `Save to Read Later` に相当する操作を `S`（Save）で表す。

## Reading session / Extension popup

| Key | Action |
| --- | --- |
| `Space` | 読み上げを開始／停止 |
| `J` / `↓` | 次の記事 |
| `K` / `↑` | 前の記事 |
| `S` | 現在のページ／記事をリーディングリストに追加 |
| `V` | 現在の元記事を外部ブラウザで開く |
| `Esc` | 読み上げ画面・ポップアップを閉じる |
| `?` | ショートカット一覧を表示 |

画面に存在しない操作は、その画面では何もしない。モバイルではタップ・スワイプ操作を残し、ショートカットは補助操作とする。
